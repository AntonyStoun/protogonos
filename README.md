# PROTOGONOS — Ткань Бытия / Протокол L-01

Тёмный техно-мистический сайт в стиле **chromomorphism**:
матовый чёрный, линии 1px без скруглений, широкая геометрическая
типографика, моноширинные цифры, топографические волны и чертеж
орбитального механизма в инверсии.

## Структура

```
protogonos/
├── index.html          — сайт (открывается напрямую, без сборки)
├── css/style.css       — оформление
├── js/main.js          — интерактив: навигация, редактор, фон, плеер
├── content/texts.js    — ВСЕ ТЕКСТЫ САЙТА (редактируемый файл)
├── media/transmission.mp4  — видео секции TRANSMISSION
└── assets/
    ├── img/            — механизм, плита L-01, Луна
    └── fonts/          — шрифты локально (Unbounded, JetBrains Mono, Inter)
```

Сайт полностью автономен: нет CDN, нет сборки, нет интернета — всё в папке.

## Публикация на GitHub Pages (5 минут)

1. Зайдите на github.com → **New repository** → имя, например `protogonos` → **Public** → Create.
2. В репозитории: **add file → Upload files** — перетащите **всё содержимое** папки `protogonos`
   (index.html, css, js, content, media, assets). Commit.
3. **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / `/ (root)` → Save.
4. Через 1–2 минуты сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/protogonos/`.
5. Ссылку на репозиторий впишите в `js/main.js` в строке `var REPO_URL = ""`.

> Важно: GitHub Pages отдаёт файлы с учётом регистра имён — оставляйте
> имена папок и файлов в нижнем регистре, как есть.

## Как менять тексты (два способа)

### Способ 1 — прямо на сайте (рекомендуется)
1. Откройте сайт, нажмите **Ctrl+E** (в любом месте страницы).
2. Кликните по любому тексту — он редактируется как в Word: удалите старое,
   напишите новое. Всё видно сразу, в дизайне сайта.
3. Нажмите **ОПУБЛИКОВАТЬ → СКАЧАТЬ texts.js**.
4. На GitHub откройте папку `content`, перетащите туда скачанный `texts.js`
   (он заменит старый) → **Commit changes**.
5. Через 1–2 минуты обновите сайт — новый текст виден всем.
   Ваши правки до публикации хранятся в браузере (черновик).

### Способ 2 — на GitHub
Репозиторий → `content/texts.js` → карандаш ✏️ → правьте → Commit.
Формат файла — понятный: каждый блок это `{ "k": "p", "x": "текст…" }`,
где `p` абзац, `h` подзаголовок, `f` формула, `q` крупная цитата,
`l` пункт списка.

## Как заменить видео
Положите новый файл в `media/` с тем же именем `transmission.mp4`
(mp4, H.264 + AAC) и загрузите в папку `media` на GitHub (замена файла).

## Локальный просмотр
Просто откройте `index.html` в браузере (двойной клик).
